📊 Approach & Query

Query Code


WITH regional_product_sales AS (
  SELECT 
    region,
    product_name,
    SUM(total_sales_amount) AS total_sales
  FROM highest_sales_by_region
  WHERE region IS NOT NULL
  GROUP BY region, product_name
),
ranked_products AS (
  SELECT 
    region,
    product_name,
    total_sales,
    ROW_NUMBER() OVER (PARTITION BY region ORDER BY total_sales DESC) AS rank_in_region
  FROM regional_product_sales
)
SELECT 
  region,
  product_name,
  total_sales
FROM ranked_products
WHERE rank_in_region = 1
ORDER BY total_sales DESC

Query Description

SQL query used CTE (Common Table Expression) to first aggregate sales by region and product, then applied ROW_NUMBER() OVER (PARTITION BY region ORDER BY total_sales DESC) to rank products within each region. Filtered for rank_in_region = 1 to identify the top product per region, ordered by total_sales descending to show highest performers first.
