Business Question: Which product has highest sales in each region?

The highest-selling products by region are: West region - iPhone 15 ($38,434.94), Midwest region - Samsung Galaxy S24 ($23,789.91), Northeast region - Samsung Galaxy S24 ($17,697.88), Southeast region - iPhone 15 ($7,835.52), and one unspecified region - Patagonia Fleece ($1,262.56).

📊 Approach & Query

Query Code


WITH ranked_products AS (
  SELECT 
    region,
    product_name,
    product_id,
    category,
    total_sales,
    total_quantity,
    ROW_NUMBER() OVER (PARTITION BY region ORDER BY total_sales DESC) as rank
  FROM highest_sales_by_region
)
SELECT 
  region,
  product_name,
  product_id,
  category,
  total_sales,
  total_quantity
FROM ranked_products
WHERE rank = 1
ORDER BY total_sales DESC

Query Description

Used a window function (ROW_NUMBER() OVER PARTITION BY region ORDER BY total_sales DESC) to rank products within each region by their total_sales value, then filtered for rank = 1 to identify the single highest-selling product per region. The Gold table already contained pre-aggregated sales totals by product and region, eliminating the need for additional GROUP BY aggregation.
