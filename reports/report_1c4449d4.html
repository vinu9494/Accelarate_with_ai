Business Question: which product has highest sales in each region?

✅ Answer

The highest-selling products by region are: West region - iPhone 15 ($38,434.94), Midwest region - Samsung Galaxy S24 ($23,789.91), Northeast region - Samsung Galaxy S24 ($17,697.88), Southeast region - iPhone 15 ($7,835.52), and one unspecified region - Patagonia Fleece ($1,262.56).

📊 Approach & Query

Query Code


WITH ranked_products AS (
  SELECT 
    region,
    product_id,
    product_name,
    category,
    rank_in_region AS total_sales,
    ROW_NUMBER() OVER (PARTITION BY region ORDER BY rank_in_region DESC) AS rank
  FROM highest_sales_by_region
)
SELECT 
  region,
  product_name,
  category,
  total_sales,
  ROUND(total_sales, 2) AS sales_amount
FROM ranked_products
WHERE rank = 1
ORDER BY total_sales DESC

Query Description

Used ROW_NUMBER() window function partitioned by region and ordered by rank_in_region (sales amount) descending to identify the top-selling product in each region. Filtered for rank = 1 to extract only the highest-selling product per region, then ordered results by total sales to show the strongest performing region-product combinations first.
