📊 Approach & Query

Query Code


SELECT 
    region,
    total_sales,
    total_quantity_sold,
    ROUND(total_sales / NULLIF(total_quantity_sold, 0), 2) AS avg_price_per_unit
FROM highest_sales_by_region
WHERE region IS NOT NULL
ORDER BY total_sales DESC

Queried the highest_sales_by_region table to extract all available dimensions. Calculated average price per unit (total_sales / total_quantity_sold) to derive additional insights. Filtered out null regions and ordered by total_sales descending to rank regional performance.
