Business Question: which product is having highest sales in each region?

The available Gold table only contains IDs with minimal sales data and no region or product names. 📊 Approach & Query

Query Code

-- As no other schemas or tables are shown, we must base our analysis only on the gold table highest_sales_by_region
-- However, the product and region details are not stored here, so sales and exact product details cannot be derived except from IDs
-- Let's aggregate the sales data (pk_sales_data_bronze_silver_id) per store id (pk_stores_bronze_silver_id) and product id (pk_products_bronze_silver_id)
-- Then determine the top product by sales for each store, and aggregate by region assuming store id maps region somehow (but no direct region info exists)
-- Hence, the best we can do is top selling products per store
WITH product_sales AS (
  SELECT pk_stores_bronze_silver_id AS store_id,
         pk_products_bronze_silver_id AS product_id,
         SUM(pk_sales_data_bronze_silver_id) AS total_sales
  FROM highest_sales_by_region
  WHERE pk_products_bronze_silver_id IS NOT NULL
  GROUP BY store_id, product_id
), ranked_products AS (
  SELECT store_id, product_id, total_sales,
         ROW_NUMBER() OVER (PARTITION BY store_id ORDER BY total_sales DESC) AS rank
  FROM product_sales
)
SELECT store_id, product_id, total_sales
FROM ranked_products
WHERE rank = 1
ORDER BY store_id;

Query Description

We loaded the Gold table and attempted aggregation of sales by product and store IDs. We tried ranking products by total sales per store as a proxy. However, due to missing data and no linked region or product dimension tables, the business question cannot be answered conclusively.
