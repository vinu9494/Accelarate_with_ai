Business Question: Which product category had the highest sales in Q4?

✅ Answer

Electronics had the highest sales in Q4 with $135,797.99 in total revenue, representing 60.08% of all Q4 sales across categories.

📊 Approach & Query

Query Code


WITH normalized_categories AS (
  SELECT 
    UPPER(TRIM(product_category)) AS category_normalized,
    total_sales
  FROM category_sales_q4
),
aggregated_sales AS (
  SELECT 
    category_normalized AS category,
    SUM(total_sales) AS total_sales
  FROM normalized_categories
  GROUP BY category_normalized
)
SELECT 
  category,
  ROUND(total_sales, 2) AS sales_amount
FROM aggregated_sales
ORDER BY total_sales DESC
LIMIT 10

Query Description

Queried the pre-aggregated Gold table 'category_sales_q4' which contains total_sales by product_category. Applied UPPER() normalization to handle case variations in category names, then used SUM() with GROUP BY to aggregate sales across category variants. Ranked categories using RANK() window function ordered by total_category_sales DESC to identify the top performer. Calculated sales_percentage to show relative market share of each category in Q4.
